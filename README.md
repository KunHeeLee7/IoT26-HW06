# IoT26-HW06  

### **Objective**
* Learn how to deploy and configure the Ultralytics YOLO framework on a Raspberry Pi 5 environment.
* Implement a real-time computer vision system to recognize vehicles and car license plates from an external display or camera source.

### **Tasks Performed**
* **Environment Setup**: Configured Raspberry Pi OS and installed the Ultralytics package along with necessary dependencies like PyTorch and OpenCV.
* **Model Selection**: Deployed a lightweight YOLO pre-trained model optimized for edge computing and on-device inference on the Raspberry Pi 5.
* **Inference Pipeline**: Developed a Python inference script to capture, process, and analyze video streams or image inputs in real time.
* **Object Recognition**: Successfully detected and framed cars or vehicle license plates displayed on a computer monitor, validating model accuracy.
* **Automation Control**: Implemented a conditional logic system that triggers a GPIO output (e.g., lighting an LED) upon successfully identifying a registered/valid license plate.

### **Development Environment**
* **Device**: Raspberry Pi 5
* **Language**: Python  
* **Framework / Library**: Ultralytics YOLO, PyTorch, OpenCV  
* **Tools**: SSH, Visual Studio Code (VS Code) / Thonny IDE, External Monitor / Camera Input
